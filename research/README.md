# Research Project — Olist Temporal Distribution Shift

Reproducible study of how temporal change in the Olist e-commerce data relates to the generalization of a machine-learning model that predicts delivery delays.

## Research question

How does temporal change in the Olist e-commerce data affect the generalization performance of a machine-learning model that predicts delivery delays?

## Status

| Part | Status |
|---|---|
| H1 — target prevalence shift | Done (7.82% → 6.69% → 3.49% across partitions) |
| H2 — feature distribution shift | Done (PSI, KS, Jensen–Shannon) |
| H3 — random vs. chronological evaluation | Done as a supplementary diagnostic (`random_vs_chronological.py`) |
| H4 — performance over later time windows | Done (monthly performance, errors, calibration, Brier score) |
| Rolling-origin evaluation, confidence intervals, conditional drift (P(Y\|X)), recalibration | Not done — listed as future work |

The findings describe distribution differences and performance changes. They do **not** establish a causal mechanism or strict concept drift.

## Reproducing

From the repository root, with the Olist CSV files in `data/raw/` (they are not committed):

```bash
pip install -r requirements-dev.txt
python research/random_vs_chronological.py   # writes reports/random_vs_chronological.csv
jupyter notebook research/01_temporal_distribution_shift.ipynb
```

Raw Olist CSV files must remain local and must not be committed to GitHub.
